## 🛠️ My Custom Open-Source Tools
Here are some of the tools I developed to solve real-world pentesting and networking problems:

*   🚀 **[zain-network](https://github.com/zainroot3/zain-network)**: A powerful, custom network management and automation tool written entirely in **Bash Scripting**.
*   🛡️ **[xss-listener](https://github.com/zainroot3/xss-listener)**: A specialized listener written in **Python**.
