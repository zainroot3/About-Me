### 🛡️ About

I'm a security researcher and penetration tester with a strong focus on **web application security**, currently active in bug bounty programs and building out a manual-exploitation-first methodology. I favor understanding the underlying logic of a vulnerability over relying on automated tooling — that approach has shaped how I recon, test, and report.

- 🔭 Currently working through **PortSwigger Web Security Academy** labs while actively hunting on bug bounty programs
- 🎯 Focused on web application penetration testing, with an eye toward broader red team work
- 💻 Daily driver: **Kali Linux (Bare Metal)**, 2+ years
- 🧠 Philosophy: *"If you can't do it manually, you don't know how it works."*
